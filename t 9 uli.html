# TugasWeb-P9-LaravelSetup
## Instalasi
1. Pastikan php -v (>= 8.2), composer -V, node -v
2. composer create-project laravel/laravel blog
3. cd blog, buat database blog_db di phpMyAdmin
4. Isi .env: DB_CONNECTION=mysql, DB_DATABASE=blog_db,
   DB_USERNAME=root, DB_PASSWORD=(kosong)
5. php artisan serve → http://127.0.0.1:8000

## Struktur folder
- app/ → Model & Controller
- resources/views/ → View (Blade)
- routes/web.php → daftar route
- database/ → migrations, factories, seeders
- public/ → document root
- .env → konfigurasi rahasia (jangan di-commit)
